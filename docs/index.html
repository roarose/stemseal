stemseal

Small LLMs guess at calculations.
stemseal gives them verified cells to call instead.

작은 LLM은 계산을 어림짐작합니다. stemseal은 그 대신 부를 수 있는 검증된 세포를 줍니다.

GitHub PyPI pip install stemseal

How a cell works

1 · pure

One small deterministic function. No I/O, no clock, no randomness.
작고 결정적인 함수 하나.

2 · proven

Passes 20+ ground-truth cases before it enters the bank.
정답 사례 20개 이상 통과.

3 · sealed

Locked by sha256. A locked cell never changes; a fix is a new version.
sha256으로 잠기고 바뀌지 않음.

If no cell fits, the model gets an honest “not available” instead of an invented answer. 맞는 세포가 없으면 지어낸 답 대신 “없음”을 돌려줍니다.

Honest limits. One test set, written by us, mostly Korean business arithmetic — your tasks will differ. Cells help only where a cell exists; writing, translation and judgment stay with the model.

우리가 만든 시험 하나, 주로 한국어 업무 계산입니다. 세포가 있는 계산에서만 돕습니다.

Install

pip install stemseal
stemseal verify     # re-checks every lock and ground-truth case

Runs entirely on your machine. No server, no account, no dependencies, no telemetry.

Connect to your model (MCP)

{
  "mcpServers": {
    "stemseal": {
      "command": "stemseal-mcp",
      "env": { "STEMSEAL_MODEL": "qwen2.5:3b" }
    }
  }
}

Tools: find_cell · call_cell · list_cells · request_cell. Works with any MCP client — LM Studio, Claude Desktop, Ollama front-ends.
