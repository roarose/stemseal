# stemseal 출시 서명 도구

세포 출시(cells-N)에 서명하는 도구입니다. 출시 책임자의 PC에서만, 열쇠가 든 USB를 꽂았을 때만 씁니다. 패키지(pip, uvx)에는 들어 있지 않습니다.

## 준비 (한 번)

1. 이 폴더(`tools/signer`)를 **주 USB와 예비 USB 둘 다**에 복사합니다. 그다음에는 USB 안의 것만 씁니다.
   도구는 작업 스레드가 알려 준 커밋(검수를 거쳐 병합된 직후)에서 받은 ZIP의 것을 씁니다.
2. 명령 창에서 한 번 실행합니다: `python -m pip install cryptography`
   도구는 `python -I`로 실행되어 사용자 폴더에만 설치된 꾸러미는 읽지 않습니다. 설치했는데도 "cryptography 꾸러미가
   필요합니다"가 나오면 관리자 권한 명령 창에서 `python -m pip install --no-user cryptography`를 실행합니다.

## 열쇠 만들기 (한 번, 약 15분)

USB 두 개(주, 예비)를 꽂고 `열쇠만들기.bat`를 더블클릭합니다.

- 주 열쇠 USB와 예비 열쇠 USB의 드라이브 문자(예: E, F)를 차례로 입력합니다.
- 주 열쇠의 암호와 예비 열쇠의 암호를 **서로 다르게** 정해 각각 두 번 입력합니다(12자 이상).
- 암호는 종이 두 장에 하나씩 적고, **두 USB 어느 것과도 다른 곳**에 둡니다. USB 하나와 그 암호 종이가 함께 있으면 그것만으로 서명할 수 있기 때문입니다.
- 드라이브 문자를 입력했는데 "고정 드라이브"라고 나오면, 지금 꽂은 USB가 맞는지 확인하고 `네`(또는 `y`)를 입력합니다. 일부 USB 메모리와 외장 SSD는 윈도우가 고정 드라이브로 알려 줍니다.
- 화면에 나오는 **공개 열쇠 두 줄**만 작업 스레드에 붙입니다. 공개 열쇠는 비밀이 아닙니다.
- USB 안의 `.pem` 파일(비밀 열쇠)은 어디에도 올리거나 보내지 않습니다.

## 출시에 서명하기 (출시마다, 약 3분)

작업 스레드가 "cells-N 준비됨, 지문 ab12cd34ef567890"(16글자) 메시지와 Release 초안을 올린 뒤에 합니다.

1. 주 열쇠 USB를 꽂고 `서명하기.bat`를 더블클릭합니다.
2. 화면의 출시 번호, 세포 목록, 지문(16글자)을 봅니다. 도구가 같은 커밋의 `trusted_releases.json`과 먼저 대조하고, 다르면 서명하지 않습니다. 지문이 스레드 메시지와 같으면 `y`를 입력합니다.
3. USB 드라이브 문자와 암호를 입력합니다.
4. 바탕화면에 생긴 `release.json.sig`를 GitHub Release 초안 화면에 끌어다 놓고 **Publish release**를 누릅니다.
5. USB를 뽑습니다.

주 USB를 잃었으면 예비 USB(도구 사본이 들어 있음)와 예비 열쇠 암호로 같은 순서를 밟습니다. 그다음 "열쇠를 잃었거나 도난당했을 때"를 따릅니다.

## 열쇠를 잃었거나 도난당했을 때

1. 곧바로 작업 스레드에 알립니다(무엇을, 언제 잃었는지. 암호나 열쇠 파일은 올리지 않습니다).
2. 작업 스레드가 **그 열쇠를 폐기하는 세포 출시**를 준비합니다. 남은 열쇠로 그 출시에 서명합니다. 서명 화면에 "이 출시가 폐기하는 열쇠"가 나오니, 잃은 열쇠의 앞 16글자와 같은지 확인합니다.
   0.2.4부터의 사용자는 이 출시를 받으면 잃은 열쇠를 더 믿지 않고, 그 열쇠로 서명된 출시에서 받은 세포도 쓰지 않습니다.
3. 잃은 열쇠를 목록에서 빼고 새 예비 열쇠를 넣은 새 stemseal 버전을 냅니다.
4. 사용자에게 stemseal을 새 버전으로 올리라고 알립니다(저장소 README, 릴리스 노트, 이슈).

한계:
- 사용자는 `stemseal update`를 실행해 그 출시를 받기 전까지는 잃은 열쇠를 믿습니다.
- 잃은 열쇠를 가진 쪽도 남은 열쇠를 폐기할 수 있습니다. 두 열쇠가 서로를 폐기하면 사용자는 어느 열쇠도 믿지 않고, 세포 출시를 받지 않습니다(패키지 세포와 직접 만든 세포는 계속 씀). 이때는 새 열쇠를 넣은 새 stemseal 버전으로만 돌아옵니다. 잃은 열쇠만 믿게 되는 일은 없습니다.
- 0.2.4보다 옛 버전은 열쇠 폐기를 읽지 않습니다. 그래서 4번의 알림이 중요합니다.
- "예비 열쇠로 세포 회수 출시를 낸다"는 것은 세포를 회수할 뿐입니다. 열쇠 폐기는 2번입니다.

## 지킬 것

- 서명하는 동안 이 PC에서 Claude 원격 세션(Remote Control)을 켜 두지 않습니다.
- 암호는 키보드로만 입력하고 채팅, 스레드, 파일에 적지 않습니다.
- 도구는 아무것도 보내지 않습니다. `서명하기`는 공개된 release.json을 받기만 합니다.
- 도구를 바꿀 때는 검수를 거친 새 판을 USB에 직접 복사합니다.
